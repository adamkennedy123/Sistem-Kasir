# Kafe POS — Titik Temu Kopi

Sistem Kasir dan Pemesanan Kafe berbasis web yang digunakan untuk mengelola transaksi, produk, kategori, laporan, serta aktivitas kasir dan admin.

---

## 1. Tech Stack

Project ini menggunakan teknologi berikut:

### Backend
- Laravel
- PHP
- MySQL

### Frontend
- Blade Template
- Tailwind CSS
- JavaScript
- Chart.js

### Database
- MySQL

### Tools
- Composer
- XAMPP / Laragon
- Git
- Visual Studio Code

---

## 2. Fitur Aplikasi

### Admin
Admin memiliki akses untuk:

- Dashboard
- Mengelola produk
- Mengelola kategori
- Melakukan transaksi
- Melihat laporan
- Melihat statistik penjualan
- Melihat peringatan stok rendah

### Kasir
Kasir memiliki akses untuk:

- Dashboard
- Melihat transaksi
- Mengelola proses transaksi sesuai hak akses

---

## 3. Requirements

Pastikan komputer sudah memiliki:

- PHP 8.x atau sesuai versi Laravel yang digunakan
- Composer
- MySQL
- Apache
- Node.js dan NPM jika diperlukan
- Git

Disarankan menggunakan:

- XAMPP
atau
- Laragon

---

## 4. Installation

### Step 1 — Clone Repository

Clone repository project:

```bash
git clone URL_REPOSITORY
```

Masuk ke folder project:

```bash
cd nama-project
```

---

### Step 2 — Install Dependency Laravel

Jalankan:

```bash
composer install
```

Jika project menggunakan dependency frontend, jalankan:

```bash
npm install
```
